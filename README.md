# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 카페 메뉴판 웹페이지입니다.
`index.html` 파일 하나로 이루어져 있고, 설치나 어려운 도구 없이 크롬 같은 브라우저에서 바로 열립니다.

- 가게: 브릿지 커피 (광주 북구 비엔날레)
- 소개: 매일 직접 볶는 스페셜티 커피

## 화면 구성

1. **맨 위**: 가게 이름, 위치, 한 줄 소개
2. **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트 (누르면 해당 메뉴만 보임, 처음엔 "전체")
3. **메뉴 목록**: 메뉴 이름, 가격, 한 줄 설명
   - 사장님 추천 메뉴에는 배지가 붙고 카드가 더 강조됩니다
   - 품절 메뉴는 흐려지고 "오늘 품절" 도장이 찍힙니다
4. **맨 아래**: 영업시간과 "전화 걸기" 버튼 (휴대폰에서 누르면 바로 전화 연결)

디자인은 칠판에 분필로 그린 빈티지 카페 메뉴판 느낌(하늘색 + 크림색)이며, 휴대폰 화면(가로 390px)에 맞춰져 있고 가로로 눕히거나 컴퓨터로 봐도 깨지지 않습니다.

## 사용 방법

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
PC에서는 브라우저 창을 좁게 줄이면 휴대폰 화면과 비슷하게 볼 수 있습니다.

## 메뉴 고치는 방법 (비개발자용)

메뉴 정보는 `index.html` 맨 위의 **"메뉴 수정 구역"** 한곳에 모여 있습니다. 이 목록만 고치면 화면이 알아서 바뀝니다. 메뉴 한 줄은 이렇게 생겼습니다.

```
{ 이름: "아메리카노", 가격: "4,500원", 설명: "산미가 적은 고소한 원두", 추천: 0, 품절: 0 },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | 큰따옴표 안의 글자만 바꿉니다. 예) `"4,500원"` → `"4,800원"` |
| 메뉴 추가하기 | 같은 칸 안에서 메뉴 한 줄을 통째로 복사해 아래에 붙여 넣고 글자만 바꿉니다 |
| 메뉴 지우기 | 그 메뉴 줄을 통째로 지웁니다 |
| 오늘 품절 표시 | 그 줄의 `품절: 0` 을 `품절: 1` 로 바꿉니다. 다시 팔면 `0` 으로 되돌립니다 |
| 사장님 추천 달기 | 그 줄의 `추천: 0` 을 `추천: 1` 로 바꿉니다. 떼려면 `0` 으로 되돌립니다 |
| 새 칸(예: 빵) 만들기 | 칸 하나(`이름: "디저트"` 부터 `},` 까지)를 복사해 붙여 넣고 글자를 바꿉니다 |

주의: 큰따옴표(`"`)와 줄 끝의 쉼표(`,`)는 지우지 마세요. 카테고리 버튼은 칸 이름에서 자동으로 만들어집니다.
더 자세한 설명은 `index.html` 맨 위의 한국어 주석에 있습니다.

그 밖에 직접 고칠 수 있는 곳:

- 가게 이름 / 소개 / 위치: `<header>` 안의 글자
- 영업시간 / 전화번호: 맨 아래 `<footer>` (전화번호는 `href="tel:..."` 와 화면 글자를 같이 바꿉니다)
- 색깔: `<style>` 위쪽 `:root` 의 색 설정
- 배지 글자("사장님 추천", "오늘 품절"): 메뉴 수정 구역 위쪽의 `추천글자`, `품절글자`

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 메뉴판 본체 (HTML, CSS, JavaScript가 모두 들어 있음) |
| `CLAUDE.md` | 이 프로젝트에서 Claude와 작업할 때 지키는 규칙 |
| `자료/기획시트.png` | 가게 정보와 메뉴가 적힌 기획시트 |
| `index_플랫멤피스_백업.html` | 이전 디자인(플랫 + 멤피스 스타일) 보관본 |
| `index_글래스모피즘_백업.html` | 이전 디자인(유리 느낌) 보관본 |

## 참고

- 손글씨 글꼴(Gaegu, 나눔 펜 스크립트)은 Google Fonts에서 불러옵니다. 인터넷이 안 되면 고운 돋움 → 맑은 고딕으로 자동 대체됩니다.
- 전화번호(`062-000-0000`)는 예시 번호입니다. 실제 번호로 바꿔 주세요.
